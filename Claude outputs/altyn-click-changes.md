## 2. Что изменено

**P0**
- Удалены таймер, «свободные места», чип в шапке, бонус «до конца месяца», фраза про «10 дней» и чужой рейтинг 2ГИС.
- Вместо них — честный текст из ТЗ: «Работаю над ограниченным числом проектов одновременно…». Кнопка теперь «Узнать ближайшую дату старта».
- WhatsApp-заглушку `+7 700 000 00 00` заменила на `https://wa.me/message/SEVFCLAYNOANG1`. Номер на сайте не выводится. Та же ссылка добавлена в сообщение об успешной отправке и в сообщение об ошибке формы.

**P1 — доступность**
- Форма:
  - видимые `<label>`, пометки «(обязательно)» и «(необязательно)», `autocomplete` (name / tel / url), подсказка к формату контакта;
  - ошибки выводятся под полями с `aria-invalid`, фокус переходит на первое пустое поле;
  - после успешной отправки фокус переходит на заголовок «Заявка отправлена!»;
  - серверная логика и honeypot не менялись.
- Портфолио: каждая карточка — `<button>`, открывается через Tab → Enter или Space.
- Модалка:
  - `role="dialog"`, `aria-modal`, `aria-labelledby`;
  - фокус при открытии попадает на кнопку «Закрыть», Tab не выходит за пределы окна, Esc закрывает;
  - после закрытия фокус возвращается на карточку;
  - у кнопок ←/→/× есть подписи, у скриншотов — alt «экран N из 5».
- Мобильное меню: `aria-expanded`, `aria-controls`, подпись «Открыть/Закрыть меню», закрытие по Esc.
- FAQ: `aria-expanded` и `aria-controls`. Закрытые ответы скрыты от скринридера.
- Карточки опций: `aria-pressed`.
- Для клавиатуры добавлено видимое фокус-кольцо.
- Контраст по WCAG AA:
  - текст на золотых кнопках стал тёмным (было 2.2–3.2:1, стало 5.7–8.3:1);
  - `golddeep` → `#7E5B1C`;
  - eyebrow на светлом фоне стал темнее;
  - граница полей формы — 3.9:1.

**P1 — движение и производительность**
- `prefers-reduced-motion`: бегущая строка останавливается, reveal и прочие переходы срабатывают мгновенно. Состояния (FAQ, модалка, опции) работают как раньше.
- С H1 снята анимация появления: это LCP на мобильном. Если JS не загрузился, контент всё равно виден.
- Tailwind CDN заменён сборкой `src/input.css → dist/styles.css`: 27.9 КБ, 6.5 КБ в gzip. Из запроса шрифтов убраны неиспользуемые начертания 500.
- Устранён горизонтальный скролл на 390/375/360px: длинные кнопки теперь переносят текст.

**P2**
- Портфолио: стопка → кейс сразу по клику. Стопка сохранена. Кнопка «Смотреть все проекты» по-прежнему раскрывает сетку.
- Добавлены живые ссылки ELARA, Alba, ProRemont.
- Первый экран: 3 факта рядом с CTA — «Лендинг под ключ — 120 000 ₸», «5–12 рабочих дней», «Работаю лично». H1, CTA и подзаголовок не менялись.
- Ссылки в футере и мобильном меню получили увеличенную зону нажатия.
- Добавлен `_headers` с базовыми заголовками безопасности (nosniff, Referrer-Policy, запрет встраивания во фрейм, Permissions-Policy). CSP не добавляла.

## 3. Проверка

Проверено в Chromium (Playwright) с реальными шрифтами, но без деплоя:

- 1440 / 1280 / 768 / 390 / 375 / 360 — горизонтального overflow нет;
- полный путь по Tab: меню → hero CTA → карточки портфолио → опции → поля формы → FAQ → футер; мест, откуда нельзя выйти, нет;
- модалка: открытие Enter/Space, удержание фокуса, стрелки, Esc, возврат фокуса;
- форма: пустая отправка, ошибка сервера (502), успешная отправка на мок `/api/lead`;
- reduced motion;
- ошибок JS нет;
- визуальное сравнение до/после на 1440 и 390 — регрессий не видно;
- Lighthouse (локально, мобильный профиль): Performance 98, Accessibility 100, LCP 1.8 с, CLS 0, TBT 0 мс. Это лабораторные цифры с локального сервера, не реальные Core Web Vitals.

**Не проверено здесь:** Edge и реальные iPhone/Android, сама Cloudflare-функция на проде, реальные CWV после деплоя.

## 4. Как собирать CSS

```bash
npm install
npm run build      # src/input.css → dist/styles.css
npm run watch      # during development
```

`dist/styles.css` лежит в репозитории, поэтому Cloudflare Pages ничего собирать не нужно. После правок классов в `index.html` запускайте `npm run build` и коммитьте обновлённый CSS.
