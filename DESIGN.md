# Altyn Click — Золотая орбита

User-pinned world: surreal digital architecture, metallic sculpture and a scroll-controlled journey. The core sculpture is a polished gold knot held inside an elliptical orbit. It repeats at five positions in a single Three.js scene; three actual portfolio screenshots become framed planes along the route.

The camera moves only in response to native scrolling. It stops for most of the long gallery and approach sections. No wheel, touch or keyboard interception, no idle animation, and no delays imposed on the HTML content.

Dark olive #171b16 is the exhibition space. Warm paper #eae9e0 is the reading surface for the portfolio. Gold #dcc27d carries the sculpture, the principal action and typographic emphasis. Manrope sets the functional voice; Cormorant italic echoes the sculpture's continuous contours in selected phrases. The Impeccable italic-serif advisory is acknowledged as an intentional material relationship; it is not treated as a test failure. The fallback CSS lighting is surface modelling, not a glowing UI control.

All content remains visible before JavaScript. On reduced motion, Save-Data, WebGL failure, sustained expensive draws or manual toggle, the static orbit replaces the scene. The mobile camera stays on a straight axis and uses fewer mesh segments and lower device pixel ratio.

Impeccable context, animate, craft-floor and audit guidance were used. The roll service was unreachable, so the roll was degraded; the user's explicit visual brief takes precedence. The detector found small functional text, which was raised to 12px. Review boundary: this environment's browser disables WebGL, so the true 3D render still requires verification on a WebGL-capable device.
